## 采集配置

```python
results = collector.search_batch(
    keywords=KEYWORDS,
    max_notes_per_keyword=150,  # 非登录上限
    deduplicate=True,
    retry_count=3,
    timeout_per_keyword=120,   # 秒
)
```

## 数据质量说明

- 数据来源：小红书网页搜索（xhs.cn）
- 去重方式：单关键词内 noteId 去重 + 全局去重
- 数据时效：xsec_token 有时效，链接型字段采集后尽快使用
- 不含评论区：当前版本暂未覆盖评论

## 使用场景建议

1. **新品上市追踪**：采集竞品关键词，监控口碑变化
2. **KOL 筛选**：按粉丝量 + 互动比筛选合作达人
3. **负面监控**：监控「避雷」「踩坑」等关键词下的品牌提及
4. **内容策划**：分析高赞笔记的标题规律，指导内容创作
